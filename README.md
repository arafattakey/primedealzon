# PrimeDealZon

> Best Deals. Best Prices. Every Day.

Amazon affiliate deals site focused on Home & Kitchen, Coffee, Bedding, Cookware, Storage, and Cleaning.

## Live Site
https://arafattakey.github.io/primedealzon/

## Structure
- `index.html` – Homepage with deals grid, categories, blog preview
- `blog.html` – Blog listing page
- `privacy.html` – Privacy policy
- `disclaimer.html` – Affiliate disclaimer
- `404.html` – Custom 404 page
- `css/style.css` – All styles (Charcoal + Warm Amber theme)
- `js/products.js` – Product data with ASINs
- `js/main.js` – UI logic (filter, hamburger menu)

## Affiliate Tag
`primedealzo02-20`

## To Deploy
1. Edit `js/products.js` to update product ASINs and prices
2. `git add .`
3. `git commit -m "update"`
4. `git push`
